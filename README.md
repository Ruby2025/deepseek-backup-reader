# DeepSeek 备份阅读器 使用说明

v1.0 · 2026-11-16

把 DeepSeek 官方导出的聊天备份（一堆 json 文件）变成和网页版差不多的阅读界面：左边是对话列表，右边是对话内容，重新生成和重新编辑过的消息可以用 `‹ 2 / 3 ›` 翻页。

- **这是个人制作的第三方工具，不是 DeepSeek 官方产品。**
- **完全离线**：所有内容只在你自己电脑的浏览器里读取，不联网，不上传任何数据。
- **只读**：阅读器不会修改你的备份文件。
- **开源**：MIT 许可，可以自由使用、修改和分发。

## 下载

请到本页面右侧的 **Releases** 下载 `DeepSeek备份阅读器.zip`，解压后使用。

不建议在文件列表里逐个下载文件：那样下载的 `重命名备份.command` 会丢失可执行权限，在 Mac 上双击会提示「没有权限」（处理方法见下文「Mac」一节）。

## 压缩包里有什么

| 文件 | 用途 | 是否必需 |
|---|---|---|
| `DeepSeek阅读器.html` | 阅读器本体，Mac 和 Windows 通用 | 必需 |
| `重命名备份.command` | Mac 用：把备份里的文件名从一串 id 改成对话标题 | 可选 |
| `重命名备份.bat` | Windows 用：功能同上 | 可选 |
| `README.md` | 本说明 | — |
| `LICENSE` | 开源许可（MIT） | — |

## 第一步：从 DeepSeek 导出备份

1. 打开 DeepSeek 网页版，点击左下角的头像。
2. 进入「设置」→「数据管理」→「导出所有历史对话」。
3. 等待生成后下载压缩包，并**解压**。

解压后会得到一个类似 `deepseek_data-2026-11-15` 的文件夹，里面有 `chat_session_index.json` 和 `chat_sessions` 文件夹。

## 第二步：把文件放在一起

新建一个文件夹（名字随意），把阅读器和解压出来的备份文件夹都放进去。以后每次导出的新备份也放在这里：

```
我的DeepSeek备份/
├── DeepSeek阅读器.html
├── 重命名备份.command        （Mac）
├── 重命名备份.bat            （Windows）
├── deepseek_data-2026-11-15/
│   ├── chat_session_index.json
│   └── chat_sessions/
└── deepseek_data-2026-12-20/   （以后的备份）
```

## 第三步：打开阅读器

1. 双击 `DeepSeek阅读器.html`，它会在浏览器里打开。推荐使用 **Chrome 或 Edge**。
2. 点击「打开备份文件夹…」，选择上面那个总文件夹（例子里的 `我的DeepSeek备份`）。
3. 浏览器询问是否允许查看文件时，选择允许。

Chrome 和 Edge 会记住上次的文件夹，下次打开时点「重新打开」即可。Safari 和 Firefox 也能用，但每次都要重新选择文件夹。

## 阅读器能做什么

- **切换备份**：文件夹里有多个备份时，左上角会出现下拉框。
- **翻页**：一条消息有多个版本时，下方显示 `‹ 2 / 3 ›`。默认显示的是导出时你最后停留的那条分支，点「回到原分支」可以还原。
- **搜索**：在搜索框输入文字会按标题筛选；按回车搜索所有对话的正文，点击结果直接跳到那条消息。
- **深度思考和联网搜索**：默认折叠，点击展开。
- **图片**：备份里带的图片会直接显示。
- **导出**：右上角「导出 Markdown」，导出当前显示的这条分支。

## 可选：把文件名改成对话标题

官方导出的文件名是一串 id（例如 `3c666a4d-1308-….json`）。如果你想在文件夹里直接看出每个文件是哪个对话，可以运行重命名脚本。**阅读器不依赖这一步，改不改名都能正常读。**

脚本会处理它所在文件夹里的所有备份，可以反复运行，已经改过名的会自动跳过。标题重复的对话会在文件名后加上创建时间。每个备份里会生成一份 `重命名对照表.csv`，记录 id 和新文件名的对应关系。

### Mac

双击 `重命名备份.command`。

- **提示「无法打开，因为无法验证开发者」**：右键点击文件 → 选择「打开」→ 再点「打开」。只需要做一次。
- **提示「没有权限」**（通常是因为文件不是从 Releases 的压缩包里解压出来的）：打开「终端」，输入 `chmod +x `（注意末尾有个空格），把文件拖进终端窗口，按回车，然后再双击。
- **提示「没有找到 python3」**：打开「终端」，输入 `xcode-select --install` 并按提示安装，然后再双击。

### Windows

双击 `重命名备份.bat`。

- **提示「Windows 已保护你的电脑」**：点击「更多信息」→「仍要运行」。
- 不需要安装任何东西，用的是 Windows 自带的 PowerShell。

## 常见问题

**打开文件夹后提示没有找到备份？**
确认选的是解压后的文件夹（或它的上一级），里面要有 `chat_session_index.json` 和 `chat_sessions`。压缩包需要先解压。

**列表里有些对话是灰色的？**
说明索引里有这个对话，但备份里没有对应的文件。

**有些图片显示「图片未包含在备份中」？**
DeepSeek 的导出里没有带上这张图片，阅读器无法恢复。

**全文搜索第一次很慢？**
第一次搜索时要把所有对话读一遍建立索引，对话多的话需要等几秒，之后就快了。

## 已知限制

- 目前只在 DeepSeek 导出格式版本 3 上验证过。如果 DeepSeek 以后调整导出格式，部分内容可能显示不出来。
- 数学公式按原文显示，没有排版。
- 上传的非图片文件（txt、pdf 等）只显示文件名，DeepSeek 的导出里不包含文件本身。
